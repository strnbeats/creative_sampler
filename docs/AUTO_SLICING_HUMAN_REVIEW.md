# Auto Slicing Human Listening Evaluation

Локальный плеер помогает сравнивать исходный PCM и планы Transient / Hybrid для 15 подтверждённых primary-кандидатов. Он использует WAV-копии и JSON, созданные Offline Runner. Оценки алгоритмических результатов остаются пустыми, пока человек их не заполнит.

## Запуск

Из корня репозитория выполните:

```sh
python3 tools/auto_slicing_validation/review_server.py
```

Сервер напечатает адрес вида `http://127.0.0.1:8765`. Откройте его в браузере. Сервер слушает только loopback-интерфейс и работает без внешних сервисов. Для остановки вернитесь в окно терминала и нажмите `Ctrl+C`.

Локальные результаты должны находиться в `tests/fixtures/auto_slicing/results/corpus-curation/`. Плеер берет очередь из `curated_candidates.csv` и `pcm-primary/manifest.pcm.local.csv`, включая только записи `primary` со статусом `accepted`. Reserve-кандидаты и технические sample assets в очередь не попадают. Отдельный отсутствующий или повреждённый PCM/JSON покажет ошибку у соответствующего кандидата, не скрывая остальные.

## Прослушивание и сравнение

- Выберите материал в очереди или отфильтруйте её по Drums, Melodic, Vocals и статусу оценки.
- `Original` показывает и воспроизводит весь PCM WAV.
- `Transient` и `Hybrid` показывают границы из соответствующих `result.json`. Клик по waveform выбирает содержащий позицию slice; справа отображаются его номер и длительность.
- Используйте Play/Pause/Stop для исходника, Play slice для выбранного интервала, Repeat для повтора, Previous/Next для перехода между слайсами и Play sequence для полного прохода по всем слайсам.
- Позиции переводятся из исходных PCM frames в секунды по sample rate; диапазоны используют полуоткрытый интервал `[startFrame, endFrame)`. До показа плана сервер проверяет покрытие без пробелов и пересечений, а также совпадение границ со slice intervals.
- Переключайтесь между Transient и Hybrid, чтобы сравнить тот же исходник. Совпадающие планы явно помечаются как идентичные; интерфейс не добавляет искусственных отличий.

Последовательное воспроизведение использует один непрерывный проход по исходному диапазону `[0, totalFrames)`. Это соответствует полному упорядоченному набору слайсов, поскольку планы обязаны покрывать исходник без пропусков и наложений. Отдельный slice запускается по его фактическим frame boundaries.

## Оценки и сохранение

Для текущей стратегии заполните Boundary quality, Attack preservation, Tail preservation, Musical usability, Overall quality, Verdict и комментарий. Перейдите ко второй стратегии, заполните её независимо, затем при желании укажите предпочтение Transient, Hybrid, Equal или Neither. Все поля начинаются пустыми. Черновики сохраняются в интерфейсе при переключении материала; нажмите `Save evaluation`, чтобы записать их на диск.

Плеер расширяет, а не заменяет локальный файл:

`tests/fixtures/auto_slicing/results/corpus-curation/runner-primary/human_review.csv`

Существующие строки, пользовательские колонки и прежнее общее поле `comments` сохраняются. Новые оценки записываются в отдельные колонки для каждой стратегии; исходный статус пригодности источника не преобразуется в оценку алгоритма. CSV обновляется атомарной заменой. После перезапуска сервера оценки считываются из CSV.

Статус `reviewed` означает, что для обеих стратегий заполнены Overall quality и Verdict, а также выбрано общее предпочтение. Частичное заполнение отмечается `in_progress`; пустая оценка — `unreviewed`.

## Ограничения

- Плеер предназначен для локального исследования и не подключён к production UI, AudioImporter или DSP.
- Он воспроизводит исходные WAV и участки исходника, но не рендерит отдельные WAV для слайсов и не вводит промежутки между ними.
- Визуальные waveform и границы считываются локально; музыкальные выводы и оценки должен внести человек.
- Оригинальные CAF и локальные PCM/JSON остаются вне Git.
